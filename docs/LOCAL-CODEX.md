# Codex 本地版

本分支允许本地提交，禁止推送和自动发布。

新增皮肤「杜发星」：在标题右上角的皮肤菜单选择，预览和标题同步显示。头部保持素材宽高比；移动时嘴部张合，暂停时停止，预览独立播放。

本地打包使用已有 Cocos 3.8.6 / 1.0.9 Windows 运行库，重新编译本分支全部游戏脚本并登记新增素材。运行库目录仅用作读取来源，输出到全新的暂存目录。

```powershell
node cocos/tools/build-local.cjs <兼容运行库目录> <typescript.js绝对路径> <新的暂存目录>
./cocos/tools/package-local.ps1 -Stage <暂存目录>
```

产物：`build/installer/贪吃蛇安装包.exe`。使用 Windows 自带 .NET Framework 编译器 打包，无需安装额外编译器。打开后选择一个独立文件夹，完成后通过桌面「贪吃蛇」启动。本地包不注册系统卸载条目；关闭游戏后删除专用安装文件夹和快捷方式即可移除。用户存档沿用游戏原有存储方式。

此包为 1.0.9 基础上的 Codex 本地定制版本，不是 GitHub 的新正式发布版本。


杜发星技能「吐痰」：游戏中按空格，从嘴部向随机方向吐出淡黄色圆球；缓慢移动、遇边界反弹，蛇头吃掉固定 +40 分，不触发增长或双倍。冷却 20 秒，暂停时球和冷却一起停止。P 暂停或继续。其他皮肤保留空格技能入口，后续添加技能。
